# Módulo 1 – Toma de Decisiones

**Tema:** elección del tema del Proyecto Final de Estudios (Grupo 11) mediante una matriz de decisión multicriterio.

## Contenido

- `Modulo1_Toma_de_Decisiones_Marsonet.pdf`: informe del módulo.
- `build.py`: script en Python que calcula la matriz, el análisis de sensibilidad y genera los gráficos y el PDF.

## Resumen

Se compararon cuatro alternativas de tema con 7 criterios ponderados (escala 1 a 5):

| Alternativa | Puntaje |
|---|---|
| **A. Viviendas modulares industrializadas (Square Housing)** | **4,40** |
| B. Planta de valorización de orujo vitivinícola y olivícola | 3,35 |
| C. Segunda vida de baterías de litio para fincas | 3,25 |
| D. Mantenimiento predictivo con IoT e IA para la agroindustria | 3,30 |

El análisis de sensibilidad muestra que la elección de la alternativa A es robusta. Solo cambiaría si el criterio de riesgo pesara el 42 % o más de la decisión.
